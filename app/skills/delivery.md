# ทักษะ Delivery/QA — ติดตั้ง GEO/AEO และผลิตคอนเทนต์ที่ AI หยิบไปตอบ (ระดับโลกด้าน technical SEO + answer engine optimization)

## บทบาท
ทำให้เว็บลูกค้า "อ่านได้ ค้นเจอ และถูกอ้างอิง" โดยเครื่องมือค้นหาและผู้ช่วย AI แล้ววัดผลจริงทุกสัปดาห์

## ลำดับงานติดตั้ง (ทำตามลำดับ อย่าข้าม)
1. เข้าถึงได้: หน้าแรกตอบ 200 · ไม่ noindex · soft-404 ตอบ 404 จริง · www กับ apex ชี้ที่เดียว
2. บอทอ่านออก: เนื้อหาอยู่ใน HTML ตั้งแต่โหลด (ถ้าเป็น CSR ต้อง prerender) · canonical ชี้ตัวเอง · แต่ละ URL มีเนื้อหาของตัวเอง
3. เปิดทางบอท AI: robots.txt อนุญาต GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-Web, PerplexityBot, Google-Extended · ชี้ sitemap
4. ตัวเชื่อม: /geo (ดัชนีคอนเทนต์), /llms.txt (มีลิงก์), /geo-sitemap.xml บนโดเมนลูกค้าเอง (ไม่ใช่โดเมนเรา) · ลิงก์จากหน้าหลักของเว็บมาที่ /geo (กันหน้ากำพร้า)
5. Google: เชื่อม Search Console · ส่ง sitemap · ขอ index ราย URL ของคอนเทนต์ใหม่
6. วัดต่อเนื่อง: มอนิเตอร์คำถามเป้าหมายบน Google และ AI 3 เจ้า ทุกสัปดาห์ · สุขภาพเว็บทุกสัปดาห์ · ความสดของคอนเทนต์

## มาตรฐานคอนเทนต์ (ตรวจก่อนเผยแพร่ทุกชิ้น)
- ตอบคำถามจริงที่ลูกค้าถาม AI ชิ้นละ 1 คำถาม · ย่อหน้าแรกตอบตรง (TL;DR) ภายใน 2–3 ประโยค
- โครง: คำตอบสั้น → รายละเอียดเป็นหัวข้อย่อย (คำถามย่อย) → ลิสต์/ตาราง/ขั้นตอน → FAQ 2–4 ข้อ → ชวนติดต่อแบบไม่กดดัน
- ข้อเท็จจริงของแบรนด์มาจากเว็บจริง/ข้อมูลที่ลูกค้าให้เท่านั้น ห้ามแต่งราคา ที่อยู่ รางวัล ปีก่อตั้ง · ไม่มีคำโฆษณาต้องห้าม
- Schema: FAQPage (+HowTo เมื่อเป็นขั้นตอน, +Organization/LocalBusiness ที่หน้าหลัก) · title ≤ 60 · meta description 50–160 · ภาษาตรงกับลูกค้า (ไทยเป็นหลัก อังกฤษเมื่อตลาดต้องการ)
- ลิงก์ภายในไปหน้าบริการที่เกี่ยวข้อง 1–2 ลิงก์ · รูปประกอบมี alt text

## คุณภาพที่ "ผ่าน"
คะแนน AEO ขาดได้ไม่เกิน 1 ข้อ · ไม่มีข้อเท็จจริงที่ตรวจไม่ได้ · อ่านแล้วตอบคำถามได้โดยไม่ต้องคลิกต่อ
