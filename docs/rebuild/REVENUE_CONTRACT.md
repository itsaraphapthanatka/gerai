## ที่มา

ระบบแสดงที่มา 4 มุมคู่กัน:
1. แรกที่รู้จัก
2. ล่าสุดที่มีความหมาย (ขอแผน / กดนัด / นัด / ยืนยันข้อมูล — ดูจากผู้ติดต่อทุกคนในบัญชี)
3. พันธมิตรแนะนำ
4. ลูกค้าบอกเอง (ทีมกรอก)

กติกาการนับ:
- แต่ละมุมให้เครดิตเต็ม 1 บัญชีกับที่มาเดียว ผลรวมของแต่ละมุมเท่ากับจำนวนบัญชีพอดี และเงินต่อมุมเท่ากับยอดจริงพอดี ไม่บวกข้ามมุม และไม่อ้างว่าอะไรทำให้ปิดการขาย
- ไม่มีข้อมูล = "ไม่ทราบ" ไม่เดาเป็นเข้าตรงหรือ AI
- นับเป็น "ผู้ช่วย AI" เฉพาะเมื่อเว็บที่พามาเป็น chatgpt / perplexity / gemini / copilot / claude โดย analytics ตรวจผู้ช่วย AI ก่อน google. เพื่อไม่ให้ gemini.google.com ถูกนับเป็นการค้นหา
- **ข้อจำกัดที่แสดงในหน้าเสมอ:** การส่งต่อส่วนตัว (LINE/แชต) และการเปลี่ยนอุปกรณ์มองไม่เห็น
- **ส่งออกสาธารณะ** (`public_summary`) ใช้ allowlist ได้แค่เวอร์ชันนิยาม ช่วงเวลา จำนวนบัญชี และจำนวนต่อที่มาแรก ไม่มีเงิน ไม่มีโดเมน ไม่มีอีเมล และไม่มี id

## ต้นทุน

| ส่วน | มาจาก |
|---|---|
| ค่า API จริง (ส่งมอบ) | `ai_visibility.cost_usd` ของแบรนด์ที่มีใบเสร็จ |
| ค่า API จริง (หาลูกค้า) | `ai_visibility` ของแบรนด์อื่น + งบทดสอบ AI ที่ปิดยอดแล้ว (`budget_reservations` committed) |
| งบที่จองยังไม่ปิดยอด | แสดงแยก ไม่นับเป็นค่าใช้จ่าย · งานที่ล้มแล้วคืนงบไม่นับ |
| ค่าแรง / เครื่องมือ / ประมวลผล / อื่น ๆ | ทีมกรอกที่หน้า แยกหาลูกค้า/ส่งมอบ ติดป้ายว่าเป็นค่าจริงหรือค่าประมาณ |

- แปลง USD เป็นบาทด้วย setting `fx_usd_thb` ถ้าไม่มี จะแสดงเป็น USD และไม่คำนวณกำไร
- **กำไรขั้นต้นจากการส่งมอบ** = เงินสุทธิของงวด − ต้นทุนส่งมอบ แสดงเมื่อมีอัตราแลกเปลี่ยนและมีต้นทุนค่าแรงส่งมอบของงวดนั้นแล้ว ถ้าขาด จะบอกว่าขาดอะไรแทนตัวเลข ต้นทุนหาลูกค้าแสดงแยก

## ยังไม่ครอบคลุม

- ยังไม่นับค่า API ของงานอื่น (คอนเทนต์ / ค้นหา Serper) เพราะยังไม่มีบันทึกค่าใช้จ่ายจริงต่อครั้ง
- ยังไม่มีอัตราการต่ออายุและการหยุดชะงัก (stall) แบบตัวเลข
- ยังไม่ได้ทดสอบ Postgres
