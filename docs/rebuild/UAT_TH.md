# UAT ภาษาไทย — ทดสอบโดยผู้ใช้จริงแต่ละบทบาท (stage 19)

## เตรียม (ทำครั้งเดียว · รีเซ็ตได้ทุกเมื่อ)

1. สร้างข้อมูลทดสอบที่แยกขาด (ข้อมูลสมมติทั้งหมด ไม่ต่อเน็ต ไม่ส่งอะไรจริง):
   ```bash
   .venv/Scripts/python.exe scripts/uat_seed.py --db C:/temp/jorai-uat/uat.db
   ```
2. เปิดเซิร์ฟเวอร์ UAT:
   ```bash
   .venv/Scripts/python.exe scripts/uat_seed.py --db C:/temp/jorai-uat/uat.db --serve
   ```
   เปิดที่ http://127.0.0.1:8790 (ฟังเฉพาะเครื่องนี้)
3. บัญชีและรหัสผ่านอยู่ที่ `C:/temp/jorai-uat/uat_logins.txt` ไฟล์นี้อยู่นอก repo ห้ามส่งต่อหรือ commit
4. **รีเซ็ต** = ปิดเซิร์ฟเวอร์ → ลบโฟลเดอร์ `C:/temp/jorai-uat` → ทำข้อ 1 ใหม่

ข้อมูลเริ่มต้นใน UAT:
- เปิด flag ทุกตัว ยกเว้น `scheduler_lease`
- งบทดสอบ AI = 0 เพื่อไม่ให้มีการเรียก AI แบบเสียเงิน
- ไม่มี SMTP / LINE / Stripe / WordPress จริง

**หลักฐานที่ต้องเก็บทุกข้อ:** ภาพหน้าจอ + เวลา + ผลที่เห็น ผ่าน/ไม่ผ่าน ใส่ในตารางท้ายเอกสาร

> **เช็กอัตโนมัติแล้ว:** `uat_fixture_smoke.py` ตรวจว่าสร้างข้อมูลได้ ทุกบทบาทเปิดหน้าเริ่มต้นได้ และสิทธิ์ถูกต้อง การทดสอบโดยคนยังจำเป็นสำหรับการอ่านข้อความ ความเข้าใจ และหน้าตา
